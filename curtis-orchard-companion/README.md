# curtis-orchard-companion

The Vite + React + TypeScript app for the Curtis Orchard Visitor Companion.

Project overview, current status, architecture notes, and deployment details
live in the [repository README](../README.md). This file only covers running
the app locally.

Requires Node 24 and pnpm 10.

```
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # VITE_BASE=/<repo>/ for a GitHub Pages project site
pnpm lint
```
