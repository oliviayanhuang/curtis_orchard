# Staff quick guide

The staff preview is designed around exceptions: normal hours are already present, so a routine update should take only a minute or two.

1. Open **Staff preview** from the header or page footer.
2. Confirm U-Pick apples and Country Store apples separately.
3. Review weather-sensitive activities. Choose **Open**, **Closed today**, **Temporarily closed**, or **Not confirmed**.
4. Write a short visitor notice when conditions need explanation.
5. Select **Review & publish**, check the summary, then publish.

The visitor Today view updates immediately and shows the publication time. **Undo last publish** republishes a previous state as a new revision; it does not silently erase history.

## Important prototype limitation

This build stores staff preview changes only on the current device. It is appropriate for review and workflow testing, not for a live multi-device operation. Production launch requires shared storage, staff authentication, security rules, and Curtis-owned accounts.
